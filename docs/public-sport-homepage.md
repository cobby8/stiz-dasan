# 공개 홈페이지 스포츠 스타일 적용

## 범위

- 사용자가 선택한 강한 스포츠 방향으로 공개 홈페이지의 실제 렌더링을 변경했다. 검정·흰색 바탕, 주황색 포인트, 각진 카드와 짧은 구역 간격을 공통 규격으로 사용한다.
- 홈, 학원 소개, 프로그램·요금/순서, 시간표, 수업찾기, 연간 일정, 공지 목록·상세, 갤러리, FAQ, 약관·개인정보, 신청 안내·체험·수강·유니폼, 특강 목록·상세·신청, SHOP·상품 프레임, 공개 로그인·가입·앱 설치 안내를 대상으로 한다.
- 실제 메뉴와 링크, 설정 소개문, 공개 자료 조회, 신청 검증·단계, 수강료 계산, 서버 액션과 API는 유지한다. 관리자·선생님·학부모·기사님 업무 화면의 라벤더 스타일은 대상에서 제외한다.
- 운영 DB, 실제 신청·등록·청구·발송·결제, 푸시와 배포는 실행하지 않는다.

## 구현

- `PublicSiteTheme`와 `public-site-path.ts`로 공개 경로만 구분한다. 공통 색상은 `.stiz-public-sport` 아래 CSS 변수로 제한한다.
- 공개 화면은 라이트를 기본으로 하며 기존 테마 전환을 제공한다. 공개 테마 저장값을 분리해 업무 화면의 기존 테마 규칙을 유지한다.
- 메뉴와 계정 기능은 유지한다. 후속 수정으로 768px 이상에서는 주요 메뉴를 표시하며, 좁은 PC·태블릿과 큰 글씨에서는 메뉴를 별도 줄에 배치한다. 휴대폰에는 ‘메뉴’ 글자가 있는 서랍 버튼을 사용한다. 닫힌 서랍은 접근을 막고, 열린 서랍은 키보드 포커스를 내부에 유지하며 닫은 뒤 원래 버튼으로 돌아간다.
- 기존 입학 가이드도 실제 표시 중인 메뉴를 기준으로 안내한다. 예전 768px 분기를 유지하면 태블릿·큰 글씨에서 숨은 데스크톱 메뉴를 강조하는 문제가 있어 세 단계의 UI 분기만 맞췄다.
- 홈은 기존 공개 갤러리 사진을 대표 이미지로 사용한다. 공지를 한 곳으로 모으고, 긴 소개는 펼쳐보기로 보존했다. 근거 없는 누적 인원·만족도 숫자는 제거했다. 영상·사진·후기는 기존 자료와 표시 조건을 유지한다.
- 프로그램의 반복 제목, 넓은 제목/본문 간격, 신청 카드·단계 표시의 과도한 여백을 줄였다. 요금표는 좁은 화면에 맞게 조정하고 필터는 자체 영역에서 넘긴다.
- 사진 확대 창 닫기는 안전 영역과 터치 크기를 확보한다. 특강 고정 신청바 아래에는 내용을 가리지 않도록 별도 여백을 둔다.

## 검증 환경과 한계

- `.tmp/sport-public-qa/`의 소유 실행기는 운영 연결 없이 별도 PostgreSQL·소스 복사본·Next 생산 빌드를 사용한다. 원본 환경 파일을 읽거나 복사하지 않는다.
- 공개 화면에서 수집했던 사진·프로그램·수업·코치·공지·일정 자료를 QA용 DB로 재구성했다. 운영 DB의 완전한 복원본이 아니며, 학생·계정·등록은 합성 자료다.
- 4106 프록시는 GET/HEAD만 허용하며 실제 접수·인증·결제·발송을 차단한다. 사진은 로컬 캐시, SHOP은 공개 상품 fixture를 사용한다. 외부 상품 iframe과 영상의 외부 서비스 자체는 검증 대상이 아니다.
- 신청 조회 액션을 브라우저에서 합성 응답으로 대체하는 검사는 UI 단계 검증이며 실제 운영 신청 처리 검증과 구분한다. 대체 코드는 제품에 포함하지 않는다.
- 모바일 폭 재현과 실물 휴대폰 검증은 구분해 기록한다.

## 2026-10-22 사용자 후속 수정

- 특강 목록·상세·직접 신청의 날짜는 KST 한국어로 표시한다. 누락·잘못된 날짜는 원문 대신 확인 안내를 사용한다. 서버의 마감·종료·취소를 날짜 계산으로 다시 열지 않는다.
- 종료·마감·모집 예정·취소 상태에는 잔여석/신청 유도를 제거한다. 전 수업 만석·대기 불가는 ‘전 수업 마감’, 수업이 없으면 ‘수업 안내 예정’으로 배지·본문·버튼·직접 신청을 통일한다. 모르는 좌석 수는 문의로 표시하고 임의로 정원을 잔여석으로 쓰지 않는다. 정상 수업/대기 신청은 유지한다.
- 연간 일정은 1~12월 가로 선택과 하나의 열린 월 패널로 바꿨다. 최초 한국 현재 월과 해당 탭이 바로 보이며 ‘이번 달’ 복귀, 연도 변경, 방향키·Home·End, 화면 회전 시 선택 탭 정렬을 제공한다. 공식 수강월·수업일·상세창과 기존 5분 재조회는 보존한다.
- 헤더는 768px 이상 주요 메뉴를 표시한다. 좁은 PC·태블릿·큰 글씨에서는 별도 메뉴 줄을 확보하며, 휴대폰은 ‘메뉴’ 글자를 함께 표시한다. 입학 가이드도 실제 메뉴를 펼쳐 안내한다. 첫 측정 전 안내창 폭을 확정하고 표시 후 위치를 재측정하며, 빠른 확인 클릭의 단계 누락을 막기 위해 불필요한 강조 전환 효과를 끈다.
- API·서버 조회·가격 계산·신청 POST·운영 DB·업무용 라벤더 화면은 변경하지 않았다. 검증용 자료·계정은 기존 격리 환경의 합성이며, 운영 접수와 구분한다.
