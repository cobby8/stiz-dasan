> 2026-11-09 작성. 원장 승인(d-phase1): **지금 문구 그대로 + 머리말만 [스티즈농구교실] 로 통일**, 수강신청서 안내의 다비치 제휴 할인 문장은 뺌.
> **본문은 코드(src/lib/messaging/parent-alimtalk-templates.ts 의 PARENT_ALIMTALK_TEMPLATES)와 글자 하나까지 같아야** 한다.
> 알림톡은 등록한 문구와 다르면 발송이 실패한다. 문구를 바꾸려면 코드·이 문서·카카오 템플릿을 **같이** 고치고 재심사를 받는다
> (테스트 tests/parent-alimtalk-templates.test.mjs 가 이 문서와 코드 틀이 같은지 검사한다).
> 체육관 대관 6종은 따로 있다: docs/kakao-alimtalk-rental-templates.md

## 공통

- 유형: **기본형 · 정보성**(이미 체험·수강·특강을 신청했거나 셔틀을 이용하는 학부모에게 보내는 처리 결과 안내). 광고 문구·혜택 홍보·이벤트 문구 없음.
- 강조 표기·이미지: 사용 안 함.
- 솔라피 «대체 발송»: **문자메시지(본문 동일)로 켬** 으로 등록한다. 실패는 두 단계라 둘 다 필요하다 —
  ① 요청 단계 실패(HTTP 오류·시간 초과)는 우리 코드가 같은 본문을 문자로 대신 보낸다.
  ② 접수 뒤 전달 실패(카카오톡 미설치·채널 차단 등)는 솔라피 대체 발송만 잡는다(코드는 접수 성공으로 본다).
- 솔라피 공식 문서 근거(«대체발송», https://solapi.com/developers/api/messages-disablesms · 2026-03-25 수정본):
  - «알림톡(ATA)… 기본적으로 대체 발송이 활성화되어 있습니다. messages.kakaoOptions.disableSms … 를 true 로 설정하지 않는 한,
    발송에 실패하면 문자(SMS, LMS)로 대체 발송을 시도합니다.»
  - 대체 조건: «disableSms false 로 설정(기본값)» + «messages.from 사전 등록된 발신번호 명시» — 우리 코드는 `disableSms: false` 를
    명시하고(`src/lib/message-dispatch.ts`) from 에 `SOLAPI_SENDER` 를 넣는다(**이 환경변수가 비면 대체 발송이 안 된다**).
  - 대체 문자 내용: «알림톡/RCS 템플릿: 템플릿 내용이 전송됨»(요청의 text 가 아님). 우리 본문 = 템플릿에 같은 값을 넣은 결과라 글자가 같다.
    버튼은 «버튼의 이름과 연결된 URL이 문자 메시지 본문에 텍스트 형태로 포함»된다.
  - API 문서는 «콘솔 템플릿의 대체 발송 설정»이 API 발송을 바꾼다는 말이 없다(API 는 disableSms 로 정한다). 콘솔 이용 가이드
    (https://solapi.com/guides/kakao-ata-guide)는 템플릿별 «대체 발송 사용 여부·발신번호·발송 문구» 설정을 설명하므로,
    **콘솔에서도 템플릿 대체 발송 = 문자메시지, 발송 문구 = 이 문서 본문 그대로** 로 맞춰 둔다(어느 쪽이 적용돼도 같은 글자).
- 템플릿 id 를 받으면 아래 «환경변수»에 넣는다(Vercel). 비어 있으면 그 안내는 지금처럼 **문자(SMS/LMS)** 로만 나간다.
- /admin/sms «자동 발송» 에서 해당 규칙의 기본 채널을 «알림톡(실패 시 문자)» 로 바꿔야 알림톡이 나간다. 순서는 상관없다
  (id 만 있고 규칙이 문자면 문자, 규칙만 알림톡이고 id 가 없으면 문자로 대체 — 어느 쪽이든 학부모는 받는다).
- 이 9종의 문구는 /admin/sms 문구 화면에서 **잠겨** 있다(«카톡 등록 문구라 수정하려면 재심사 필요» 안내). 켜기/끄기만 된다.

## 2. 수강신청서 안내

- 환경변수: `ALIMTALK_TPL_TRIAL_ENROLL_GUIDE_REVISED` · 규칙 트리거: `TRIAL_ENROLL_GUIDE_PARENT`

- 바뀐 점: 지금 문자의 «다비치안경 남양주다산점 제휴로 스포츠고글 35,000원, / 안경·고글 구매 시 10% 추가 할인…» 2줄과

  문자도 같은 틀이라 문자에서도 빠진다. 제휴 안내가 필요하면 신청서 화면에만 둔다.

  수신거부 방법 표시»를 의무로 둔다. 그래서 **우리가 본문에 직접 넣는다**:


- 스위치: Vercel 환경변수 `ALIMTALK_BMS_FREE_NOTICE=on` 일 때만 브랜드 메시지. 꺼져 있으면(기본) 자유 공지는 지금처럼 문자

## 등록 후 할 일(PM)

1. 승인된 템플릿 id 9개를 Vercel 환경변수(위 `ALIMTALK_TPL_*`)에 넣고 재배포.
2. /admin/sms «자동 발송» 에서 9개 규칙의 기본 채널 = «알림톡», 대체 = «문자» 로 바꾼다. 외부(학부모) 알림톡 채널·대체 문자 채널이 켜져 있는지 확인.
3. 원장 휴대폰으로 트리거별 1건 시험 → `NotificationDelivery.messageType='ALIMTALK'`, `fallbackUsed=false` 확인.
4. 공지 3종: 승인된 id 를 `ALIMTALK_TPL_NOTICE_CLOSURE` · `ALIMTALK_TPL_NOTICE_EVENT` · `ALIMTALK_TPL_NOTICE_MONTHLY` 에 넣는다(규칙 화면 설정은 없다 — id 가 있으면 바로 알림톡).
5. 자유 공지 브랜드 메시지: 준비되면 `ALIMTALK_BMS_FREE_NOTICE=on`. 첫 발송 전 원장 번호(채널 친구) + 친구 아닌 번호로 시험 —
   친구 아닌 번호는 문자가 오지 않고 결과에 «못 받은 학부모 1명» 이 떠야 정상.
6. 청구 2종: 승인된 id 를 `ALIMTALK_TPL_BILLING_INVOICE` · `ALIMTALK_TPL_BILLING_UNPAID` 에 넣고, /admin/sms «자동 발송» 에서
   `BILLING_INVOICE_PARENT` · `UNPAID_PARENT` 규칙의 기본 채널 = «알림톡», 대체 = «문자». 실제 발송은 발송 잠금
   (`BILLING_PARENT_SEND_ENABLED=1`)을 원장이 열어야 시작된다.
