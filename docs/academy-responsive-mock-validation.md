## 변경 내용

- 휴대폰의 전시용 틀·여백 제거, 기기 화면 폭과 안전 영역 사용. viewport 설정을 넣어 모바일 기본 980px 표시를 방지한다.
- 학부모는 오늘 수업·셔틀과 청구·요청, 선생님은 수업·메모와 출석·수강료를 넓은 화면에서 나란히 배치한다.
- 기사님은 정류장 시간순을 유지하고 넓은 화면에서 정차 정보와 탑승 명단을 나란히 배치한다. 작은 화면의 전화 버튼은 콘텐츠 폭만 사용한다.
- 관리자 상태 필터는 가로 스크롤 뒤로 숨기지 않고 줄바꿈한다. 터치 대상 44 CSS px 이상을 유지한다.
- 기존 시안의 로컬 출석·탑승 집계와 청구·위치·종료 상세창을 보존한다. 실제 기록·통화·결제·위치 수집은 실행하지 않는다.

## 검증 한계와 다음 단계

- Chrome 화면 크기·터치 모의 검사이다. 글자 200%는 계산된 본문 글꼴을 두 배로 만든 검사이며 실제 OS 접근성 설정 검증을 대신하지 않는다.
- iOS Safari·Android WebView·실제 키보드·노치·분할 화면·배터리·실제 API 연결은 이 시안 검사로 입증하지 않았다. 여백에 safe-area 설정을 넣었다는 사실만으로 실기기 합격으로 보지 않는다.
- 현재 최종 시안의 실물 검증은 미완료다. 사용자는 Android폰·iPhone 사용 가능하다고 답했으며 기기 연결·모델/OS 확인을 요청했다.
- 종전 갤럭시 탭 GPS 단기 검증은 `docs/driver-device-validation.md`에 따로 있으며 이번 최종 시안의 실물 검증으로 전용하지 않는다.
- 앱 구성은 일반 STIZ(iOS/Android, 학부모·선생님·관리자 역할 분기)와 Android 기사 앱 2종을 준비 기준으로 한다. 실제 구현·운영 전환·스토어 제출은 별도 승인 대상이다.
- 실물과 실제 앱 기능 검증 전에는 전체 검증 완료 또는 출시 준비 완료로 표시하지 않는다.
