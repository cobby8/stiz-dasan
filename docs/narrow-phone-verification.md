2026-10-20. 사용자 승인 범위는 네 역할의 겹침·불필요한 줄바꿈 수정이며, 기사님 글씨·조작 크기를 유지한다. 운영 DB·저장/API·GPS·배포는 변경하지 않는다.

## 검사 범위

- 320·360·375·390px 폭에서 브라우저로 화면을 재현한다. 앞서 실제 Android에서 확인한 554px 화면과 별개이며 좁은 실물 휴대폰 검증이라고 표현하지 않는다.
- 실제 UI 컴포넌트와 Tailwind·라벤더 테마를 사용한 격리 검사, 실제 Next 컴파일 화면을 읽는 통합 검사를 구분한다. 자료와 인증 제공자는 합성이며 실제 권한 판정 코드는 유지한다.
- 긴 학생명·보호자명·반명·정류장, 여러 학생, 연락처 유무, 당월 수강료·미납, 필터·확인창을 조사한다. 페이지 전체 넘침과 표 자체의 의도된 가로 스크롤을 구분한다.
- 버튼·입력의 경계만 맞는 것으로 완료하지 않는다. 실제 글자 줄 수·같은 행 배치·높이·글꼴·조작 크기와 캡처를 대조한다. 긴 문장의 필요한 줄바꿈은 유지한다.
- 격리 서버에서 공식 Material Symbols 글꼴을 제공한다. 통합 캡처도 같은 공식 글꼴을 시험 페이지에만 연결하며 제품 글꼴 설정을 바꾸지 않는다. 외부 운영 요청·저장·결제·발송·위치 수집은 실행하지 않는다.

## 확인된 원인과 수정

- 기사 학생 정보의 내부 줄바꿈으로 연락처가 이름 아래로 이동하고 탑승 버튼까지 별도 행으로 밀렸다. 글씨·버튼을 줄이는 대신 정보와 연락처의 배치 및 열 간격을 조정한다. 긴 정류장명은 좁은 칸 안에서 과도하게 쌓이지 않게 한다.
- 관리자 원생표에서 네 글자 이름이 세 글자와 한 글자로 나뉘었다. 이름·학년을 한 줄로 보존하되, 긴 이름·다반 검사에서 발견된 고정 열 너비와의 충돌도 함께 해결한다. 해당 표의 휴대폰 열 계산만 내용에 맞추고 표 안의 가로 스크롤을 유지한다. 640px 이상 기존 표를 유지한다. 기존 전역 셀 여백이 이미 적용되므로 불필요한 셀 여백 변경은 최종 수정에서 제거했다.
- 학부모 다음 수업의 긴 반명이 화면 폭을 넘었다. 해당 인라인 텍스트에 적용된 한 줄 제한을 풀고, 메시지·셔틀 연락 요소는 의미 단위로 배치한다.
- 선생님 연락 목록의 긴 보호자·전화와 수강료 시트의 금액·상태를 분리해 읽을 수 있도록 해당 행만 조정한다. 조회와 납부 확인 요청 동작은 유지한다.
- 선생님 출석 화면의 복귀 버튼, 학부모의 작은 화면 결제수단·셔틀 선택 문구가 단어 중간에서 나뉘지 않게 한다. 더 작은 두 폭에서만 결제수단을 두 열로 배치하며 선택값과 결제 방식은 유지한다.
