# 공개 학원 홈페이지 구성과 테마 정리

## 승인과 범위

- 2026-10-20 사용자는 실제 공개 페이지 조사 후 라벤더 퍼플 적용, 불필요한 구성 축소, 오피셜·스포츠 테마 추가와 로컬 검증을 승인했다.
- 공개 홈페이지의 메인·소개·프로그램·시간표·연간 일정·수업 찾기·신청·특강·공지·사진·FAQ·문서·가입/설치 외곽을 포함한다.
- 운영 DB·요금·수업 시각·인증·신청 검증·동의·결제·발송 로직은 변경하지 않는다. 푸시·배포는 하지 않는다.

## 구성 변경

- 첫 화면에서 소개와 체험 신청·수업 안내로 바로 이동한다. 긴 소개는 버튼 뒤 접힌 영역에 보존하고 사진은 실제 공개 사진만 사용한다.
- 고정 통계와 미확인 기존 No.1/등록률 문구는 공개 표현에서 제외한다. DB 원문은 변경하지 않는다.
- 큰 공지는 작은 소식 목록, 영상은 요청 시 펼침, 후기 전체는 가로 탐색으로 유지한다. 중복 대표 사진은 제외한다.
- 헤더는 소개·수업·소식·오시는 길과 체험 신청 중심이다. 클럽샵·유니폼·접근성·계정 기능은 보조 메뉴로 유지한다.
- 일반 브라우저의 불필요한 뒤로가기 공간은 줄이되 설치 앱에는 뒤로가기를 보존한다. 메뉴는 터치·키보드·Esc·초점 복귀와 내부 스크롤을 제공한다.
- 자동 방문 안내와 두 개의 부동 버튼 대신 도움말 한 입구를 사용한다. 둘러보기는 수업→시간표→체험의 짧은 링크 안내다. 챗봇 요청·응답 계약은 유지한다.
- 시간표의 필터·건수·카드/표 전환을 한 도구줄로 모은다. 내부 메모는 서버의 공개 자료 투영에서 정제하므로 숨은 클라이언트 자료에도 남지 않는다. 관리자 원본·공개 준비물 안내는 보존한다.
- 체험/정규 선택을 먼저 보여주고, 유니폼은 보조 링크로 이동한다. 선택 수업을 신청서에 자동 전달하는 기능은 이번 범위에서 구현하지 않았다.
- 종료 특강은 지난 프로그램으로 접고 종료 상태에 맞춰 표시한다. 원본 ISO 날짜는 한국 날짜로 표시한다.
- 공지·갤러리·FAQ·약관은 실제 내용이 빨리 나타나게 제목/카드 간격을 줄인다. 필수 사업자·판매자·약관·동의 내용은 보존한다.

## 세 테마

- 기본 `lavender`: 밝은 바탕·부드러운 퍼플·둥근 카드.
- `official`: 흰 바탕·네이비·구분선과 사진 중심, 절제된 제목/모서리.
- `sport`: 짙은 바탕·밝은 글자·오렌지·굵은 제목과 선명한 구분. 상태 배지의 배경과 글씨를 함께 맞춘다.
- 같은 화면·데이터·기능을 공유한다. 공식 로고 원본은 색을 바꾸지 않는다. 공개 전용 CSS 변수로 업무 화면의 라벤더 규격과 분리한다.
- 비교 주소: `/?previewTheme=lavender`, `/?previewTheme=official`, `/?previewTheme=sport`. 일반 이용자에게 개발용 메뉴를 추가하지 않는다. 운영 저장 설정은 새로 만들지 않았다.
- 공개 기본은 라이트이며 기존 저장된 다크 모드가 새 홈페이지를 덮지 않는다. 큰 글씨 설정은 유지·복원한다.

## 실제 자료 개발 미리보기

- 운영 연결은 SELECT 전용으로 자료를 읽은 뒤 종료한다. 앱은 가린 로컬 복사본만 사용한다.
- 기존 업무 자료 외 공개 조건이 있는 공지·갤러리·FAQ·후기와 공개 소개 필드만 허용 목록으로 추가했다. 공개 판정 컬럼이 없으면 해당 표를 생략한다.
- 이미 공개된 이미지 18개를 임시 앱에 복사하고 1개는 조회 실패로 제외했다. 인증·쿠키·서명 주소·외부 리다이렉트를 사용하지 않으며 이미지 파일은 Git에 포함하지 않는다.
- 실제 자료의 신청/청구/발송/결제는 프록시에서 차단한다. 공개 화면 조회만 허용한다. 원본 링크·결제 공급자·지도·영상·공식 달력처럼 외부 연결이 필요한 기능은 차단된 개발 환경의 결과를 운영 장애로 해석하지 않는다.
- 동의와 실제 제출 흐름은 기존 합성 검증을 유지한다. 실제 고객 토큰·주문·계정 생성은 실행하지 않는다.

## 검증과 한계

- 최종 실행본: `http://127.0.0.1:4090/`. 현재 소스 873개와 빌드 복사본의 해시 불일치 0개, 생산 빌드 성공. 운영 SELECT 연결은 앱 실행 전에 종료됐고 저장 기능은 차단 상태다.
- 최종 결과: 전체 회귀 2,289건 + 학생 보호 5건, 실제 공개 페이지 249/249건, 공통 UI 행동 39/39건, TypeScript 검사와 diff 검사 통과. 검사 보고서는 `.tmp/public-pages-preview/report.json`, `.tmp/public-site-browser/report.json`에 있으며 개인정보 자료와 이미지는 Git에 포함하지 않는다.
- 변경된 TS/TSX 48개에 ESLint를 재실행하고 HEAD와 대조했다. 기존 오류 37→26, 경고 10→8이다. 남은 26개는 기존 any 계열이며 시간표의 기존 any[] 변환도 유지된다. 메인 공개 사진의 일반 img 사용 경고 2개는 명시적 lazy/우선순위·비율 지정 상태다. 전체 lint가 깨끗하다는 의미는 아니다.
- 연간 공식 달력은 격리 환경의 읽기 실패로 미리보기에 0건이다. 이 상태로 청구 근거를 확정하거나 발행하지 않는다. 실제 지도/영상/본사샵/소셜 인증/폼 제출·문자·결제 및 이번 실물 기기 검증은 수행하지 않았다.

- `npm.cmd test`: 기존 보호 검사와 전체 회귀. 최종 건수는 완료 기록에 남긴다.
- `node scripts/test-public-site-browser.mjs`: 실제 공통 컴포넌트·메인·시간표, 합성 자료, 3테마×320/360/768/1280/1440px. 메뉴·테마·글씨·도움말·설치 앱 뒤로가기 39검사.
- `node scripts/test-public-pages-preview.mjs`: 실제 Next 빌드의 공개16경로×3테마×5폭, 첫 화면 CTA·입력 크기·전체 넘침, 짧은 높이의 도움말·채팅 입력 검사. 저장·외부 전송 없음.
- `tests/public-conversion-presentation.test.mjs`: 실제 두 공개 페이지 직렬화 자료의 내부 메모 제외·원본 불변과 날짜/표시 정책을 실행 검증한다.
- `tests/public-preview-content.test.mjs`, `public-preview-images.test.mjs`, `real-preview-safety.test.mjs`: 공개 조건·개인정보/서명 제외·이미지 크기/리다이렉트 제한·쓰기 차단.
- 브라우저 폭·짧은 높이 재현은 실물 휴대폰·OS 키보드 검사와 구분한다. 본사 샵 iframe, 실제 소셜 로그인·문자·결제·지도·영상 공급자 호출은 이번 검증에서 실행하지 않는다.

## 수정 중 발견해 보완한 사항

- 320px 프로그램 목록은 기본 자동 너비와 카드 안 이중 패딩으로 11px 넘쳤다. 단일 열·최소 너비·카드 단일 외곽과 표 간격으로 수정했다.
- 스포츠 배지 글씨 대비 부족, 큰 글씨 저장값의 실제 클래스 복원, 동일 경로 테마 검색조건 변경, 설치 앱 뒤로가기를 독립 검토 후 보완했다.
- 짧은 가로 화면에서 도움말/상담창 상단이 잘리는 문제를 높이 제한·내부 스크롤로 보완했다.
