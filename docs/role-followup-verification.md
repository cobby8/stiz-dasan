## 실제 운영 세션

- 사용자 요청으로 기존 로그인 세션을 사용하는 운영 사이트의 관리자 홈, 선생님 화면, 학생 화면을 조회했다. 이동 후 로그인 화면으로 되돌아가지 않았고 관찰 범위에서 브라우저 경고는 없었다.
- 같은 세션의 학부모 경로는 관리자 홈으로 돌아왔다. 지정 자녀의 연결 상태를 별도 읽기 전용 DB 트랜잭션으로 확인했으며 현재 계정에 연결된 정식 자녀가 없는 상태였다. 운영 자료를 자동으로 연결하거나 변경하지 않았다.
- 이름만으로 계정을 연결하지 않는다. 실제 자녀 연결·정식 등록은 안정 ID와 별도 운영 승인으로 처리해야 한다.
- 기존 로그인 세션 유지 검증이며 비밀번호 재입력, OAuth 신규 로그인, 만료·탈퇴·복구 검증으로 확대해서 해석하지 않는다. 운영 배포본의 동작과 최신 로컬 구현을 혼동하지 않는다.

## 다중 역할 보강 완료

- 대표 `User.role`은 유지한다. 관리자·부원장은 관리자/선생님 보기, 교사는 선생님 보기를 사용하고 직접 인증 연결과 본인 자녀 조건을 충족할 때 학부모 보기를 추가한다. 기사에게 이번 메뉴를 추가하지 않는다.
- 학부모 보기에서는 기존 `requireVerifiedParent`와 본인 `Student.parentId` 범위를 유지한다. 이메일만으로 자녀 권한을 열지 않는다. 로그인 직후와 계속 화면은 같은 공통 판정을 사용한다.
- 공통 전환 메뉴는 관리자 프로필·선생님 메뉴·학부모 헤더·공개 계정 영역에서 공유한다. 단일 자격에는 메뉴를 숨기고 공개 페이지의 기존 계정 버튼 자리를 대체해 중복 버튼과 모바일 추가 행을 만들지 않는다.
- 수업 중 전환은 기존 저장 확인을 사용한다. 저장 실패 시 이동하지 않는다. 설치 앱 범위를 벗어나는 이동은 브라우저 화면임을 안내한다.
- 권한·실제 로그인/계속 함수 행동 검사20건, 기존 관련 검사와 독립 로그인12/공개 계정13분기를 검증했다. 최종 공통 UI104/104, 독립 초기 UI100/100 이후 중복 제거 보완104를 구분한다.
- 깨끗한 별도 소스의274파일 회귀2128/2128, 별도 학생 조회 보호5/5, TypeScript 통과. 새 UI/서버 영역 lint0이며 AdminShell의 기존 효과 내 상태 변경1건은 이번 변경과 분리한다. 전체 저장소 lint가 정리됐다는 의미는 아니다.

## 화면 전환 경고 수정 완료

- 실제 DOM 재시도 위치와 React 공식 수정 코드를 대조해 원인을 확인했다. Next16.2.12로 최소 계열 업데이트하고 직접 사용하는 React/ReactDOM19.2.3은 유지했다.
- 기존 생산90회 중12회 오류 → 같은 후보90회 오류0. 문서/Link108회, 독립36회는 별도 검사이며 합산하지 않는다. 상세 [원인·검증 기록](navigation-hydration-verification.md).
- 정상 설치 후 격리 생산 빌드·TypeScript·66개 정적 출력, 교사27조합과 역할15회 검증을 통과했다. 학부모 보기에서 본인 합성 자녀만 표시되는6회와 교사 청구창의100,000원/미납3폭을 확인했다.
- 최종 기기 빌드의3역할 관련10개 파일은 현재 소스와 바이트가 일치한다. 공개 홈 계정 버튼의 마지막 중복 제거1파일은 해당 기기 빌드와 구분하고, 별도 실제 컴포넌트104·전체 회귀·TypeScript로 검증했다.
