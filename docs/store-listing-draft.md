```

■ 학부모
· 우리 아이 수업 일정과 출결, 수업 리포트·사진을 한눈에

· 오늘 수업 반·출석 체크
· 수업 사진과 소식 올리기
· 학생 정보와 보강 관리

■ 셔틀 기사님 (Android)
· 오늘 운행 노선과 탑승 학생 확인
```

## 5. 개인정보 — Google Play 「데이터 보안」 답안

- 데이터 수집: **예** · 데이터 공유(제3자 제공): **아니요**(처리 위탁 — Supabase 저장, SOLAPI 문자, 토스페이먼츠 결제, Google Gemini 음성 변환 — 은 Play 정의상 «공유» 아님. 실제 위탁 계약 확인 후 확정)
- 전송 중 암호화: **예**(HTTPS 전용, 평문 통신 차단 `usesCleartextTraffic=false`)
- 삭제 요청 방법: **예** — 앱 안 계정 탈퇴 + 웹 https://www.stiz-dasan.kr/account/withdraw

| 데이터 유형 | 수집 | 필수/선택 | 목적 |

## 6. 연령 등급 설문 요지

폭력·성적 내용·약물·도박·욕설 없음 / 사용자 간 무제한 소통 없음(선생님→학부모 공지·사진만) / 위치 공유는 기사님 운행 위치를 해당 셔틀 학부모에게만 / 디지털 구매 없음.

## 7. 애플 4.2(최소 기능) 대응 설명 — 「심사 메모」 에 붙일 문장

```
STIZ 농구교실은 학원에 등록된 가족·직원 전용 업무 앱입니다. 웹사이트를 그대로 감싼 앱이 아니라
다음 기기 기능을 앱 안에서 직접 처리합니다.
1) 역할별 진입: 로그인 후 학부모·선생님 화면으로 자동 이동하고, 앱 밖 주소는 기본 브라우저로 분리합니다.
2) 사진 첨부: 사진 보관함·카메라를 기기 선택 화면으로 열어 수업 사진·결석 증빙을 올립니다.
3) 파일 저장·공유: 청구서·자료를 기기 공유 시트로 저장하거나 보냅니다.
4) 외부 결제 복귀: 실제 수업·셔틀·유니폼 대금은 외부 결제(토스페이먼츠) 후 앱으로 돌아와 서버에서 결과를 다시 확인합니다.
5) 안전한 세션: 로그인 정보는 앱 저장소에 분리 보관하며, 계정 탈퇴는 앱 안에서 바로 할 수 있습니다.
심사용 계정으로 학부모·선생님 화면을 모두 확인하실 수 있습니다.
```

> ⚠️ 정직하게: 원격 푸시 알림은 아직 없다. 4.2 반려 위험을 낮추려면 **네이티브 푸시(수업 소식·납부 알림)** 를 제출 전에 붙이는 것을 권한다. 위 문장에는 실제 구현된 것만 적었다 — 기능을 추가하면 문장을 늘린다.
