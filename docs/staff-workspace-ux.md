# 선생님 수업·출결 화면 정리

2026-10-19 · 로컬 검증 기록 · 푸시·배포 미실행

## 목적과 작업 그룹

선생님이 현재·다음 수업을 찾고 출결을 확인하는 데 집중하도록 반복 카드와 보조 메뉴를 줄였다. 라이트·라벤더 퍼플과 공식 로고를 유지한다.

| 그룹 | 담당 | 의존 관계 | 완료 기준 |
|---|---|---|---|
| 기존 화면·안전 경계 조사 | 읽기 전용 조사 담당 | 기존 수업·출결 계약 | 중복과 보존할 동작 확인 |
| 홈 구성 | 홈 UI 담당 | 조사 | 현재·다음 수업 우선, 완료 목록 분리 |
| 진행·출결 구성 | 진행 UI 담당 | 조사; 홈과 파일 독립 | 출결 우선, 입력·저장 보호 유지 |
| 독립 검증·검토 | tester / reviewer 병렬 | 두 UI 완료 | 화면·행동·타입·회귀 확인 |
| 통합 기록·커밋 | PM | 검증 완료 | 증거와 한계 기록, 로컬 저장 |

## 변경 내용

- 홈의 큰 통계 카드 3개를 한 줄 요약으로 줄였다. 장식과 빈 수업 계획 카드도 덜었다.
- 진행 중인 수업이 있으면 복귀를 먼저 보여주고, 나머지 수업 시작 잠금을 유지한다. 준비 수업의 주 행동은 수업 시작이다.
- 수업 내용·학생 정보·청구·공지의 반복 버튼은 각 수업의 ‘수업 준비·관리’로 접었다. 펼치기만으로 저장·발송하지 않는다.
- 완료 수업은 별도 접힌 목록에 보존한다. 모두 완료하면 ‘오늘 수업을 모두 마쳤습니다’를 표시하고 완료 수업을 다음 수업으로 다시 제시하지 않는다.
- 진행 화면의 출결 미확인 안내 3곳을 한 영역과 ‘출석부 확인’ 버튼으로 모았다. 사진·메모의 큰 점프 메뉴는 제거하고 실제 입력 영역을 유지했다.
- 학생 정보·청구·수업 시작 취소는 ‘학생 정보·수업 관리’로 모았다. 종료 고정 바에서 시작 취소를 덜어 높이를 줄였다. 취소 확인과 종료 확인은 그대로다.
- 출석 화면은 통계 4카드를 한 줄로, 학생별 독립 카드를 하나의 명단으로 줄였다. 출석·지각·결석 버튼, 학부모 사전 결석 사유와 확정 표시를 유지하고 버튼에 학생 이름과 선택 상태를 제공한다.

수정 화면은 `src/app/staff/StaffHomeClient.tsx`, `src/app/staff/sessions/[sessionId]/SessionInProgressClient.tsx`다. 공통 헤더·하단 메뉴·학생/청구 시트·API·서버 조회는 변경하지 않았다. 사진 업로더와 메모 입력은 접기 때문에 제거·재생성되지 않는다.

## 검증 경계와 남은 범위

실제 React 컴포넌트를 합성 수업·학생과 모의 액션에 연결했다. 서버 액션·DB·인증 모듈은 격리 번들에서 차단한다. 지연 로딩 학생/청구 시트, 사진 업로드·음성 입력은 모의 처리하므로 해당 공급자 통합 동작을 검증한 것은 아니다.

실제 운영 DB 쓰기·공지 발송·푸시·결제·사진 전송·배포는 하지 않았다. 소스 계약 검사와 모의 출결 저장 성공을 운영 저장 성공으로 해석하지 않는다. 배포는 결과 확인 후 별도 승인 범위다. 기사님 화면 후속 정리는 이번 그룹에 포함하지 않았다.
