# 카카오 알림톡 — 체육관 대관 신청자 안내 템플릿 (심사 등록용)

> 2026-11-08 작성. 원장 승인 문구 그대로다. **본문은 코드(src/lib/rental/gym-rental-rules.ts 의 RENTAL_APPLICANT_TEMPLATES)와 글자 하나까지 같아야** 한다.
> 알림톡은 등록한 문구와 다르면 발송이 실패한다. 문구를 바꾸려면 코드·이 문서·카카오 템플릿을 **같이** 고치고 재심사를 받는다
> (테스트 tests/gym-rental-member.test.mjs 가 이 문서와 코드 틀이 같은지 검사한다).

## 공통

- 유형: **기본형 · 정보성**(이미 신청한 사람에게 보내는 처리 결과 안내). 광고 문구·혜택 홍보·이벤트 문구 없음.
- 강조 표기·이미지: 사용 안 함.
- 변수만으로 본문을 만들지 않았다 — 모든 틀에 고정 문장(머리말·안내 문장·이용 수칙)이 있다.
- 템플릿 id 를 받으면 아래 «환경변수»에 넣는다. 비어 있으면 그 안내는 지금처럼 **문자(LMS)** 로만 나간다.
  알림톡이 실패하면 같은 본문을 문자로 대신 보낸다.

## 변수 설명

| 변수 | 들어가는 값 |
|---|---|
| `#{이용일}` | 이용 날짜와 요일. 예) 2026년 11월 16일(월) |
| `#{시간}` | 이용 시간과 길이. 예) 20:40~22:10 (1시간 30분) |
| `#{인원}` | 이용 인원 숫자. 예) 8 |
| `#{이용인원}` | 인원(+냉난방 사용 시 표시). 예) 8명 · 냉난방 |
| `#{총액}` | 입금할 금액. 예) 75,000원 |
| `#{이용료}` | 이용료. 예) 55,000원 |
| `#{보증금}` | 보증금. 예) 20,000원 |
| `#{계좌}` | 입금 계좌. 예) 하나은행 55491019425407 (예금주 권혜미) |
| `#{요금내역}` | 재원생 유료분 요약. 예) 2시간 초과 30,000원 + 냉난방 15,000원 |
| `#{사유}` | 거절 사유. 예) 그 시간에 학원 일정이 있어요 |

## 1. 체육관 대관 승인 안내

- 환경변수: `RENTAL_ALIMTALK_APPROVED`
- 보내는 때: 원장이 대관 신청을 승인했을 때(일반 신청 · 이용료 + 보증금 입금 안내)
- 유형: 기본형 · 정보성
- 변수: `#{이용일}` `#{시간}` `#{인원}` `#{총액}` `#{이용료}` `#{보증금}` `#{계좌}`
- 버튼: 선택(넣는다면 웹링크 «대관 신청 보기» https://www.stiz-dasan.kr/rental)

```
[스티즈농구교실] 체육관 대관이 승인되었습니다.
#{이용일} #{시간} · #{인원}명
입금 #{총액}(이용료 #{이용료} + 보증금 #{보증금})
#{계좌}
입금자명은 신청자 이름으로 해 주세요. 입금 확인 후 확정 문자를 드려요.
[이용 수칙]
· 실내운동화 필수
· 신청한 시간·인원 지키기
· 사용 후 정리정돈, 냉난방 끄고 퇴실
· 주차는 인근 주민센터 주차장 이용
· 수칙을 지키지 않으면 보증금이 차감될 수 있어요
```

## 심사 주의

- 광고성 표현(할인·이벤트·«지금 신청하세요» 같은 유도 문구)을 넣지 않는다 — 정보성 템플릿이 거절된다.
- «재원생 2시간 무료»는 신청한 사람에게 처리 결과(요금이 0원인 이유)를 알리는 문장이라 정보성이다. 심사에서 문의가 오면 그렇게 답한다.
- 변수 자리(`#{…}`)는 위 표의 이름 그대로 등록한다. 이름을 바꾸면 코드도 같이 바꿔야 한다.
- 계좌는 `#{계좌}` 변수로 넣는다(계좌가 바뀌어도 재심사가 필요 없게).

## 원장님이 하실 일 (쉬운 순서)

1. **솔라피 콘솔 로그인** → 왼쪽 메뉴 «카카오 채널» → «채널 연동». 스티즈농구교실 카카오톡 채널을 연결한다(채널 관리자 휴대폰 인증).
2. 연결이 끝나면 화면에 **PF ID**(채널 고유 번호, `KA01PF…` 로 시작)가 보인다. 이 값을 PM(클로드)에게 알려 준다.
3. 솔라피 콘솔 «알림톡 템플릿» → «템플릿 등록». 위 1~5번(필요하면 6번)을 **복사해 그대로 붙여 넣는다**.
   - 유형: 기본형 · 메시지 유형: 정보성
   - 거절 안내(4번)에만 버튼 «웹링크 · 대관 신청 보기 · https://www.stiz-dasan.kr/rental» 를 추가한다.
4. «검수 요청» → 카카오 심사(보통 영업일 1~3일). 반려되면 반려 사유를 PM 에게 그대로 보내 준다.
5. 승인되면 템플릿마다 **템플릿 id**(`KA01TP…`)가 생긴다. 5개(또는 6개) id 를 PM 에게 보내 준다.
6. PM 이 Vercel 환경변수(`SOLAPI_KAKAO_PF_ID`, `RENTAL_ALIMTALK_*`)를 등록하고, /admin/sms 에서
   «체육관 대관 승인·입금 / 거절 / 확정 안내 (신청자)» 규칙의 기본 채널을 «알림톡(실패 시 문자)»으로 바꾸고,
   외부(학부모) 알림톡 채널을 켠 뒤 시험 발송으로 확인한다.

> 참고: 신청자 문자는 지금 **꺼져 있다**(환경변수 RENTAL_APPLICANT_SMS_ENABLED + /admin/sms 규칙 둘 다 켜야 나간다).
> 알림톡 준비와 별개로, 켜는 시점은 원장님이 정한다. 접수 문자(신청 직후)는 남의 번호로 보낼 수 있어 계속 꺼 둔다.
