# 실제 자료를 반영한 개발 미리보기

## 승인과 목적

- 최신 개발 화면에 실제 원생·반·신청·최근 두 달 수업/출결/납부 상태·현재/다음 달 정규 셔틀 자료를 연결하는 범위를 승인받았다.
- 운영 사이트 배포·운영 DB 수정·권한 변경·발송·결제는 제외한다. 실제 이름·반·일정·금액은 보존하고 개인정보는 가린다.
- 운영 기준과 최신 코드의 관리자 메뉴는 각각 36개로 연결 주소가 동일하다. 주요 업무와 접힌 하위 업무로 배치만 바뀌었으며, 별도 축약 메뉴를 만들지 않는다.

## 실행과 자료 경계

- 실행: `node scripts/dev-real-data-preview.mjs`.
- 브라우저: `http://127.0.0.1:4090/__entry/admin`. 사용자 PC의 loopback에서만 연다. Vercel 자동 배포 차단은 유지한다.
- 운영 연결은 별도 추출기에서 `default_transaction_read_only=on`과 `BEGIN ... READ ONLY`를 함께 사용한다. 조회 전후 읽기 전용 상태를 확인하고, `ROLLBACK` 및 연결 종료 후에만 앱을 실행한다.
- 앱은 새 로컬 PostgreSQL 55476만 사용한다. 내부 Next 서버 4091은 프록시의 로컬 전용 헤더를 요구하고, 공개 입구 4090은 저장·운영 작업을 차단한다. 실제 서비스 키·메일·문자·결제·시트 인증은 앱에 전달하지 않는다.
- 원본 자료를 파일·콘솔·검증 JSON에 저장하지 않는다. 값은 메모리에서 가린 뒤 로컬 DB로 전달하며, 증거에는 건수·기간·가림 통계·소스 해시만 남긴다.
- 원래 학생·반·보호자 관계와 역할을 유지한다. 로컬 로그인용 이메일·인증 ID는 새 값이며 운영 로그인·권한을 변경하지 않는다.
- 연락처·실제 생일·개인 주소·자유 메모·사진 URL·인증 토큰·결제 거래 식별자·발송 큐는 복사하지 않는다. 생일 고정값은 개인정보 가림을 위한 값이므로 실제 연령 검증에 사용하지 않는다. 수업 날짜와 수업 고유키는 유지한다.
- 지도 좌표·실제 기사 토큰·위치 이력은 제외한다. 로컬 전용 기사 링크를 만들며 지도 경로 재계산·위치 수집은 실행하지 않는다.
- 앱 외부 연결은 프로세스에서 차단한다. 브라우저는 외부 이미지·통신·프레임·서비스워커·위치 권한을 차단하고, 공개 글꼴 파일만 별도 정적 허용한다. 외부 링크·전화·메일 클릭도 차단한다.

## 첫 자료 대조

- 26개 허용 테이블의 가린 자료를 복사했다. 학생 원본 332건, 프로그램 8개, 반 38개, 코치 7명, 수강 연결 496건, 체험 26건·수강신청 15건·수강 변경 66건·상담 처리 이력 40건·학부모 요청 1건, 청구 기초 400건·청구서 372건, 해당 월 셔틀 398건·차량 1개다.
- 신청 이력의 상태·적용일·후속 일정은 유지하지만 요청 제목과 본문은 명시적인 가림 문구이며, 실제 원문이 아니다. 사유·상담 메모·처리자 자유문자도 복사하지 않는다.
- 원생 목록의 표시 인원은 병합·상태 등 기존 목록 규칙을 적용한다. 원본 행 수 332를 활성 원생 수로 보고하지 않는다.
- 현재 기준 최근 두 달 수업·출결·결석과 현재 월 원장 조회 결과는 0건이다. 승인 기간을 임의로 늘리거나 합성 기록으로 채우지 않았다. 원장 이관 상세·특강 신청·사진·과거 전 기간까지 복제했다고 주장하지 않는다.
- 개인정보 가림: 전화 필드 1,346건·생일 필드 348건, 이메일과 인증 연결 ID 각각 324개. 업무·기간별 정규화 외 다른 운영 상태를 변경하지 않았다.

## 검증과 종료

- 자료 가림 단위 검사는 `node --test scripts/lib/real-preview-snapshot.test.mjs`, 입구 보호 검사는 `node --test tests/real-preview-safety.test.mjs`로 실행한다.
- 독립 검사에서 원본 SELECT 전용·권한 승격 없음·시간 범위·고유키 보존·개인정보 제거·외부 리다이렉트·다른 DB 포트·외부 네트워크 차단을 확인한다.
- 증거는 Git 제외 경로 `.tmp/real-data-preview/summary.json`, `source-proof.json`, `ready.json`이다. 원본 행·실제 계정 ID·비밀값은 기록하지 않는다.
- 종료: `.tmp/real-data-preview/STOP` 파일을 만들면 이 실행기가 소유한 서버·DB를 종료하고 로컬 DB와 인증 대체 빌드를 정리한다. 다른 프로젝트 서버나 운영 실행기는 종료하지 않는다.
- 중간 대조에서 빠진 신청 상태 이력을 추가했고, 로컬 기사 링크를 실제 화면의 토큰 형식에 맞췄다. 앞선 두 로컬 실행기의 서버·DB·인증 대체 빌드를 정상 정리한 기록은 `first-cleanup.json`, `second-cleanup.json`이다. 운영 링크나 운영 자료는 변경하지 않았다.
- 최종: 가림·입구 보호 단위 16/16과 독립 외부 연결 차단 6/6 통과. 실제 자료를 넣은 복사본의 전체 빌드가 성공했고, 인증 대체용 두 파일을 제외한 실제 소스 857개 해시가 일치했다.
- 실제 브라우저 1440px에서 관리자 홈·신청·원생·반·수납·정규 배차, 선생님·학부모·기사님 총 9개 화면이 200으로 표시됐다. 화면 전체 가로 넘침·한글 깨짐·페이지 실행 오류·기사 링크 오류는 없었다. 두 메뉴 영역에서 운영 메뉴 36개를 모두 대조했고 누락은 0이다. 이번 결과를 새 실기기 검사로 표현하지 않는다.
- 내부 서버 직접 접근·저장 POST·예약 작업 GET·서비스워커 GET은 모두 403이었다. 준비 완료 후 세 조회를 반복해 연결 오류 증가는 0이었다. 준비 중 Next가 아직 열리지 않았을 때의 연결 실패 1건은 최종 표시 실패와 구분한다.
- `browser-report.json`과 `final-safety.json`에는 주소 패턴·건수·상태만 기록했다. 외부 연결 시도 3건은 글꼴 생성 과정에서 차단됐으며, 로그에는 고정 차단 문구만 있다.
- 최종 미리보기는 화면 검토를 위해 실행 상태로 유지했다. 푸시·운영 변경·배포는 하지 않았다.
