## 변경 내용

- 헤더의 같은 위치에서 작은 운행 시작·종료 버튼을 제공하고 중복 날짜·큰 종료 카드·큰 설치 안내를 줄였다. 날짜 이동은 기존 공용 화면을 유지한다.
- 운행 순서, 정차 시각, 정차별 체크 수를 먼저 보여준다. 길안내는 시간 아래에 작게 두되 누르는 영역은 44px 이상 확보했다.
- 학생 이름과 탑승·미탑승 버튼을 같은 행에 배치하고, 전화·결석·자차·당일 변경 정보를 유지했다. 긴 이름은 줄바꿈한다.
- 중복 배지와 하단 안내는 간결한 문구·접힌 도움말로 정리했다. GPS 공유 실패·중단 미확인 등 필요한 경고는 접지 않는다.
- 정규 순서 수정·이동 버튼은 유지한다. 편집 시간 입력은 별도 전체 폭 행으로 두어 한국어 브라우저의 오전/오후·시·분이 모두 보이도록 했다.
- 공식 로고 원본과 기존 라벤더 퍼플 테마를 유지한다. 공용 날짜·GPS 컴포넌트와 다른 기사 화면은 변경하지 않았다.

## 표시 의미와 기능 보존

- ‘체크 N/M’은 탑승·결석·자차 기록 확인 수다. 실제 차량 진행 위치나 운행 완료를 뜻하지 않는다.
- 정규 사전 결석은 대상에서 제외하고 특강 결석예정은 체크 대상으로 남긴다. 같은 승객 키는 중복 집계하지 않는다.
- 저장 중·실패·미확인 기록은 완료로 세지 않는다. 최초 조회 실패는 0건이나 완료로 표시하지 않으며 기존 경고·잠금·조회 재시도를 유지한다.
- 빈 거점은 완료로 표시하지 않는다. 거점은 정차 순번에 포함하되 차고지 출발·학원 도착 안내 행은 순번에서 제외한다.
- 임시 노선의 기존 ‘확정 순서’ 문구를 ‘순서 확인 필요’로 바로잡았다.
- API·DB·조회 경로·저장 키·권한은 변경하지 않았다. 기존 시작/종료/설치·이동·드래그·시각·순서저장·체크 저장 함수 9개 본문을 보존했다. 체크 요약만 화면에서 계산한다.
