# 관리자 검색·필터 압축

2026-10-20. 사용자가 신청 화면의 업무 탭과 여러 필터 줄이 섞여 복잡하다고 지적했고, 검색·필터·선택 요약으로 통합하는 범위를 승인했다. 운영 DB 변경·발송·배포는 없다.

## 작업 그룹

| 그룹 | 담당 | 의존 관계 | 완료 기준 |
|---|---|---|---|
| 조사·공통·체험/수강신청 | 신청 UI worker | 사용자 승인 | 5개 업무 접근·모든 조건·검색 보존 |

## 바꾼 화면

- 신청 관리: 다섯 가로 업무 탭을 작은 업무 선택창으로 바꿨다. 체험 상태 숫자 카드·별도 날짜 선택·업무별 칩은 검색 옆 필터 한곳으로 모았다. 선택한 조건과 결과·초기화만 아래에 표시하며, 전체가 이미 표시됐을 때 반복되는 하단 건수 카드를 제거했다. 등록 동작·대기/통계/설정 접근을 보존한다.
- 원생 관리: 다섯 상태 카드를 짧은 건수 요약으로 바꾸고 반·학년·학교·상태를 같은 필터 패널로 모았다. 초기값은 활성이고 초기화해도 검색은 남는다. 전체/불러온 목록/시트 기준이라는 건수 근거와 운영 점검 안내는 유지한다.
- 특강 관리: 업무·보기 선택을 압축하고 진행/취소·상세 상태를 같은 패널에 넣었다. 명단 시즌은 대상 문맥으로 계속 표시하고 반·날짜·요일·결제·셔틀은 필터 안에 모았다. 현황은 짧은 요약으로 바꿨다.
- 공통 `CompactListFilters`는 필터 값을 갖지 않는다. 기존 각 화면이 검색·조건·조회·초기화를 계속 담당하고 공통 UI는 펼침/접힘과 배치만 담당한다. 입력17px·필터44px 터치·라벤더 토큰·Material 아이콘을 유지한다.

## 그대로 유지한 것

- 상태·업무·날짜 조건의 AND 결합, 취소 제외 기본값, 원생 활성 기본값, 추가 조회·페이지 초기화·정렬·선택 상태.
- 서버/API·저장·등록·청구·알림·CSV·시즌 전환의 기존 처리. 필터 초기화는 검색 지우기와 분리한다.
- 출결의 날짜/반, 기사 운행일, 학부모의 대상 자녀, 특강 표 열 제외 조건은 서로 다른 업무 의미이므로 일괄 필터 통합 대상으로 제거하지 않는다. 단일 상태 줄만 있는 접수 화면도 그대로 둔다.
