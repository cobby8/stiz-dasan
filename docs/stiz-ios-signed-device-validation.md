# STIZ 등록 아이폰 격리 서명 시험

## 승인과 범위
- 사용자 승인: 검증 기록 푸시, 연결 아이폰 등록, STIZ 전용 프로파일 준비, 서명 시험 앱 설치·검증.
- 대상 브랜치: `codex/stiz-app-codemagic`. 운영 홈페이지·main·TestFlight·운영 데이터·발송·결제는 제외한다.

## 준비 결과 (2026-10-28)
- 이전 검증 기록 `4a24fa09` 검증 브랜치 푸시 완료.
- Apple 조직 UPTURN LABS Co., Ltd., 팀 `UC62AC4W4T`, STIZ 앱 `kr.co.upturnlabs.stizdasan` 확인.
- 연결된 iPhone 16 Pro 한 대를 `STIZ 시험 iPhone 16 Pro`로 등록했다. 식별자 원문은 기록하지 않는다.
- 전용 Ad Hoc 프로파일 `STIZ-Dasan-AdHoc-Sandbox-2026` 생성, 단일 기기·기존 팀 배포 인증서 선택.
- Codemagic 프로파일 참조 `stiz-dasan-adhoc-sandbox-2026` 업로드·유효 상태와 STIZ 앱 ID 일치 확인.
- 기존 팀 인증서 참조 `BDR iOS App Store Distribution`은 조직 공통 서명 항목이다. BDR 앱 프로파일은 변경하지 않았다.
- 앱 전용 비공개 변수 그룹 `stiz_ios_sandbox_device`에 기기 일치 검사 값만 저장했다. 원문·값·키는 Git에 포함하지 않는다.

## 검증 구성
- 수동 워크플로 `stiz-ios-sandbox-adhoc`: Debug·실제 아이폰용 서명, `https://172.30.1.12:8453`만 허용.
- 등록 기기 한 대·STIZ 앱·조직·Ad Hoc 권한·인증서 일치와 IPA 서명을 빌드 전후 검사한다.
- 스토어 배포 단계는 없으며 IPA와 개인정보 없는 검증 JSON만 보관한다.
- 원격 오류는 단계·명령 이름·종료 번호만 표시하고 원문 프로파일·기기 식별자·환경을 출력하지 않는다.
- WebInspector는 유효한 격리 주소가 있는 Debug 앱에서만 활성화한다. 일반 앱에는 적용하지 않는다.
- 독립 QA: 프로젝트 검사 28개, 합성 서명 8건, 준비 점검·검사 연결 18건 통과. 임의 추가 업로드 명령 차단 반례 포함.
- 실제 Mac 서명·IPA 다운로드·기기 설치·역할 화면 실행은 별도 결과 확인 전까지 미검증이다.

## 설치 준비
- 기기 설치는 정상 서명·등록 프로파일을 사용한다. iOS의 인증서 검증·앱 주소 차단은 유지한다.
- 격리 서버 공개 CA만 사용자에게 전달하고, OS 신뢰 설정은 사용자가 직접 수행한다. 개인 키는 전달하지 않는다.
- Python 도구는 기존 Python 3.14 절대 경로와 전용 격리 환경을 사용한다. 시스템 별칭의 자동 설치를 사용하지 않는다.
- 잘못된 별칭 호출로 저장소 아래 생성된 임시 Python 폴더는 `.tmp`로 격리했으며 실행하거나 Git에 포함하지 않았다. 기존 Python은 유지했다.

## 증거
- 이 PC `.tmp/stiz-ios-device-install/`: 등록 완료, 프로파일 생성·연결, 비공개 변수 저장 화면과 마스킹 기록.
- 실제 서명 빌드 번호·소스 커밋·IPA 확인·실기기 결과는 완료 후 이 문서에 갱신한다.
