# 학부모 홈 구성 정리 · 검증 결과

## 목적과 작업 그룹

학부모가 자녀의 다음 수업·오늘 셔틀과 필요한 신청을 먼저 찾고, 반복되는 카드 때문에 긴 화면을 탐색하지 않도록 구성했다. 승인된 라이트·라벤더 퍼플과 공식 로고는 유지한다.

| 그룹 | 담당 | 의존 관계 | 완료 기준 |
|---|---|---|---|
| 중복·데이터 범위 조사 | 읽기 전용 조사 담당 | 기존 홈·목적지 | 선택 자녀/가족 자료와 보존 동작 확인 |
| 학부모 홈 정리 | UI 담당 | 조사·기존 데이터 계약 | 중복 제거, 실제 납부·문의·알림 유지 |
| 화면 검증·검토 | 독립 tester / reviewer 병렬 | UI 완료 | 화면·행동·권한 회귀와 검토 |
| 통합 기록·로컬 커밋 | PM | 검증 완료 | 검증 한계·다음 그룹 명시, 미배포 |

## 변경 내용

- 상단은 자녀 선택과 다음 수업·오늘 셔틀에 집중한다. 수강 반·출결 통계 반복은 아래 기록 영역으로 옮겼다.
- 모바일에서 장식이 별도 줄을 차지하지 않도록 상단 농구 장식과 일반 안내 문구를 덜었다.
- 반복되던 큰 셔틀·청구·수강 변경·리포트 바로가기 카드를 단일 요청 메뉴로 모았다. 결석·보강, 셔틀 당일 변경, 청구·수납, 수강 변경, 수업 리포트 5개다.
- 실제 납부가 필요한 청구와 납부 링크는 접기 밖에 유지하고 알림도 위쪽에 배치했다. 조회된 미납 상태를 임의로 변경하지 않는다.
- 셔틀 배정 상세, 수강·출결·수납 기록, 결석·보강 신청, 학습 피드백은 기본 접기로 정리했다.
- 바로가기·직접 해시·해시 변경 시 접힌 대상과 상위 영역을 먼저 열고 이동한다. 같은 결석 링크를 다시 눌러도 열린다.
- 셔틀 상세의 오래된 자유 메시지 ‘변경 요청’ 경로를 실제 `/mypage/shuttle`로 통일했다. 일반 학원 문의 창구는 유지한다.
- 수업·청구·셔틀은 선택 자녀 자료, 피드백·보낸 메시지·사진은 가족 자료임을 구분한다. 피드백 수를 새 소식·안 읽은 개수로 해석하지 않는다.

실제 수정 화면은 `src/app/mypage/MyPageClient.tsx` 하나다. API·서버 조회·DB·결제·푸시·알림 저장 함수 본문은 변경하지 않았다. 설치 앱의 공개 링크 제한과 기존 로고·헤더·하단 탐색도 유지했다.

## 검증

- `node scripts/test-parent-workspace-browser.mjs`: 10/10 통과. 실제 컴포넌트에서 자녀 전환, 실제 납부·전화·신청 목적지, 직접 해시 4곳, 같은 해시 재클릭, 가족 메시지와 선택 자녀 문의 제출, 명시적 읽음 호출을 확인했다.
- 관련 회귀 10파일 65/65 통과: `mypage-summary`, `parent-request-message-only`, `parent-shuttle-overview-ui`, `installed-app-scope-links`, `shuttle-preferred-vs-confirmed-time`, `kst-datetime-guard`, `parent-request-authorization`, `mypage-staff-child-access`, `mypage-redirect-loop`, `payment-parent-request` (`tests/*.test.mjs`). 로그: `.tmp/parent-ux-qa/related-regression.log`.
- `tsc --noEmit`: 통과. 변경 파일 ESLint: 오류 0, 기존 갤러리 `<img>` 경고 1 유지. `git diff --check`: 통과.
- 독립 코드 검토: 필수 수정 없음. 해시 재클릭과 알림 요청 접수 대기 권고는 정식 브라우저 검사에 반영했다.
- 독립 화면·행동 검사 25/25 통과: `.tmp/parent-ux-qa/independent-ui.json`. 1440·768·390·320px 일반/큰 글씨, 접기 전부 열기·문의 폼, 키보드, 요약 버튼, 해시 5곳·해시 변경, 자녀 전환·가족 범위·빈 상태·모의 문의/읽음 동작을 확인했다. 초기 빈 수업 안내 검사는 기록 영역 안만 탐색한 테스트 기대값을 상단의 실제 안내 확인으로 바로잡았다. 안내 중복 추가를 위한 제품 변경은 하지 않았다.
- 마지막 상단 장식·문구 축소 후 레이아웃 8/8 재통과: `.tmp/parent-ux-qa/final-layout.json`. 위 4개 화면 폭의 일반/큰 글씨에서 접힘·전체 펼침·문의 폼의 가로 넘침이 없었다. 최종 소스 SHA256: `9e235e33ecef2b663ac63d19b9a7d90606e765d14248e97ed7e5b03c593954a7`. 앞선 기능 검사와 중복 합산하지 않는다.

브라우저 검사는 합성 가족 자료와 모의 액션으로 격리한다. 운영 인증·DB·실제 문의·읽음·푸시·결제는 호출하지 않았다. 테스트의 모의 읽음·문의 접수 통과를 운영 전송 성공으로 해석하지 않는다.

화면 증거: `.tmp/parent-ux-qa/parent-1440.png`, `parent-390.png`, `parent-320.png` 및 같은 이름의 `-expanded.png`. 실제 MyPageClient·공통 테마·Tailwind를 사용했다. 본문 글꼴은 OS 고딕 대체 글꼴, 아이콘은 공식 Material Symbols 글꼴을 격리 적용했다. 서버 인증 레이아웃·고정 하단 탐색은 이번 독립 화면 검사 범위 밖이며 해당 소스도 변경하지 않았다.
