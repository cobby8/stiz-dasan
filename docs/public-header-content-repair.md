# 공개 원문·서식 복원과 한 줄 헤더 정리

후속 변경: 이 문서의 고정1280/1600px 접힘 기준은 사용자 후속 승인으로 폐기했다. 실제 여유 공간을 사용하는 최신 메뉴 판단은 [공개 헤더 실제 공간](public-header-fit.md)에 기록한다. 원문·서식 복원 및 유니폼 섹션 제거 결과는 유지한다.

## 승인과 작업 그룹

사용자는 개발 미리보기의 임의 문구를 기존 공개 원문으로 복원하고, PC 메뉴를 같은 최상단 헤더에 통합하며, 신청 안내의 유니폼 섹션만 제거하는 묶음을 승인했다. 운영 데이터·유니폼 접수 기능·기존 이력은 유지하고 배포하지 않는다.

| 그룹 | 담당 | 의존 관계 | 완료 기준 |
|---|---|---|---|
| 공개 원문 복원 | 콘텐츠 worker, PM 로컬 DB 단독 | 공개 캡처의 본문 위치·해시 확인 | 인사말 HTML·약관 107줄·개인정보 10조 일치, 임의 시설 설명 제거 |
| 헤더·신청 안내 | PM, 탐색 explorer | 메뉴·계정·가이드 식별자 조사 | 넓은 PC 한 행, 좁은 폭 같은 행 메뉴 버튼, 유니폼 섹션만 제거 |
| 통합 검증 | 독립 QA, PM 빌드·서버 단독 | 두 그룹 완료 후 실행본 생성 | 원문·서식·실제 메뉴 이동·폭 전환·쓰기 차단·최종 소스 일치 |

## 원인과 수정 경계

- 인사말의 짧은 문구는 운영 설정이 아니라 `.tmp/sport-public-qa/seed.mjs`에 넣은 임의 검증용 문구였다. 시설 설명도 소개 페이지 전체 텍스트 일부를 재사용했다. 기존 공개 내용과 같은 자료라고 볼 수 없으므로 복원했다.
- 약관·개인정보는 전체 페이지 HTML을 공백 한 칸으로 평탄화해 제목·아이콘 이름이 본문에 섞이고 문단·목록이 사라졌다. 제품의 기존 줄 단위 렌더러가 아니라 미리보기 자료 변환이 주원인이다.
- 기존 약관 컴포넌트의 `priority_high`·`gavel` 아이콘 폰트가 로드되지 않으면 코드 같은 이름이 나타났다. 불필요한 장식 아이콘은 빼고 강조 줄의 표시는 단순한 `!`로 바꿨다. 법률 문구·중요 줄 판정은 유지한다.
- 약관의 공통 Card 내부 패딩과 약관 본문 패딩이 중복돼 휴대폰에서 본문 폭을 지나치게 줄였다. 해당 약관 Card의 내부 래퍼만 패딩을 없애고 본문 패딩 한 겹과 글씨 크기를 유지한다. 공통 Card의 다른 사용처는 바꾸지 않는다.
- 헤더 CSS가 768~1279px 및 큰 글씨에서 메뉴를 강제로 두 번째 행에 배치했다. 헤더는 한 행으로 유지하고 일반 1280px 이상, 큰 글씨 1600px 이상에서 메뉴를 함께 펼친다. 그보다 좁으면 같은 행의 전체 메뉴 버튼으로 모든 링크와 계정 기능에 접근한다. 휴대폰은 버튼 문구를 ‘메뉴’로 줄인다.
- 펼쳐 둔 서랍의 버튼이 폭 변경 후 사라지면 서랍과 스크롤 잠금을 해제한다. 메뉴·가이드 식별자와 계정 조회·권한·API는 유지한다.
- 진행 중인 가이드가 숨은 PC/서랍 메뉴를 계속 강조하는 후보 오류도 재현했다. 메뉴 대상이 숨는 폭·큰 글씨 변경에서 기존 종료 정리를 실행하고 같은 단계의 메뉴 안내만 다시 시작한다. 이미 확인한 설명 카드는 반복하지 않는다. 이전 햄버거 리스너와 늦은 대기 콜백은 정리·세대 검사로 새 안내에 개입하지 않게 한다.
- 후보의 360×900px 약관은 본문 래퍼가 12,893px로 길어 화면 교차 비율이 4.7%에 그쳤다. 표시 효과의 10% 조건을 충족하지 못해 `opacity: 0`으로 남는 문제를 실제로 확인했다. 본문 일부가 진입하면 보이도록 공통 표시 효과의 관찰 기준만 0으로 바꿨다. DOM 문단 일치와 실제 가시성을 별도 검증한다.
- `/apply`의 유니폼 소개 섹션과 해당 장식 import만 제거했다. `/apply/uniform` 직접 경로·접수 API·관리자 주문·FAQ·기존 이력은 보존한다.

## 원문 출처와 정합성

출처는 2026-10-20T11:04:50.992Z에 비로그인 공개 GET과 DOM으로 확보한 `stiz-home-complete-20261020/data/public-content.json`이다. 최신 운영 설정을 다시 조회한 것이 아니며 해당 시점의 공개 원문 복원이다. 원본 캡처는 변경하지 않는다.
