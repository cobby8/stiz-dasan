# 통합 앱 실기기 시험·출시 준비표

기준일: 2026-10-28. 사용자 승인 범위는 문서 정정·시험 준비·로컬 사전점검 도구다. 운영 홈페이지 배포, TestFlight, 새 원격 빌드, 설치, 서명, 운영 DB·인증 공급자 변경은 실행하지 않는다.

## 현재 결론

**STIZ 통합 앱 1개** 안에서 관리자·선생님·학부모 화면을 전환하고, Android 기사님 운행을 연결하는 방향이다. 이전 두 앱 권고는 과거 검토안이다. iOS 기사님 위치 운행은 이번 지원 범위가 아니다.

웹 검증과 네이티브 앱 검증은 별개다. Codemagic #2는 커밋 `1954bfd8`의 Swift 정책 38+13건과 Xcode 컴파일이 통과했고, 무서명 시뮬레이터 zip 233.80 KB 생성까지 확인했다. 시뮬레이터 UI 실행·아이폰 설치·실제 로그인은 통과한 것으로 표시하지 않는다. 정본은 [원격 빌드 기록](stiz-ios-codemagic.md), [사진·인증 후속 검증](native-app-media-auth-followup.md)이다.

## 설치 전 준비

- Android: 현재 debug 패키지는 `kr.stiz.driver.unified`, release는 `kr.stiz.driver`다. 최종 이름이 아니므로 기존 앱 덮어쓰기 여부부터 확인한다. APK가 있다는 사실은 설치·실행 성공을 의미하지 않는다.
- iPhone: `kr.stiz.academy.dev`는 임시 ID다. Apple 팀·App ID·등록 기기·프로비저닝·서명된 실기기용 앱이 필요하다. Mac 없이 Codemagic을 이용할 수 있으나 시뮬레이터 zip을 아이폰에 설치할 수는 없다. [Apple 등록 기기 배포 안내](https://developer.apple.com/documentation/xcode/distributing-your-app-to-registered-devices)
- 현 시점 Android 연결은 마지막 ADB 조회에서 0대였다. 과거 Z Fold·태블릿·아이폰 시험 기록을 현재 연결·현재 앱 검증으로 재사용하지 않는다.
- 가상기기 실행은 자동 승인 검토에서 정책 차단됐다. 다른 명령으로 우회하지 않으며, 현재 도구는 기기 실행을 하지 않는다.
- 시험 시작 때 기기·앱 버전·커밋·시험 환경·기기 담당자 1명을 확정한다. 개인정보 없는 합성 학생과 합성 수업을 사용한다.

## 로컬 사전점검 사용법

`node scripts/native-release-readiness.mjs --json`으로 실행하고, `node --test tests/native-release-readiness.test.mjs`로 도구 자체를 시험한다. 코드·설정 8개 파일과 정해진 산출물·메타데이터 4개 경로만 점검한다. 환경 파일·키·인증서·DB·네트워크·기기·외부 명령에는 접근하지 않고 파일을 쓰지 않는다.

`PASS`는 해당 로컬 선언만 확인했다는 뜻이고, `BLOCKED`는 준비가 부족하거나 로컬 차단 설정을 확인하지 못했다는 뜻이다. `UNVERIFIED`는 기기·공급자·스토어 등 외부 확인이 필요하다는 뜻이다. 결과의 `releaseDecision`은 항상 `NOT_ESTABLISHED`다. 종료 코드 0도 출시 가능을 뜻하지 않으며, 로컬 차단 설정 확인 실패 시 2로 끝난다. 문서의 P0 목록 전체를 자동 판정하는 도구가 아니다.

2026-10-28 현재 소스 점검: PASS 7 / BLOCKED 2 / UNVERIFIED 8. 차단 2건은 iPhone 설치용 서명 빌드와 AppIcon이다. 이 숫자는 공급자·가족 요청 전달·통합 운행 등 수동 확인 사항을 완료 처리하지 않는다.

최종 검증: 전용 시험 13/13, 전체 `npm test` 2,569/2,569 및 학생 보호 5/5 통과. 독립 tester가 추가 자동 실행 workflow·주석 속 false·누락 manifest의 잘못된 통과를 재현했고 수정 후 모두 차단됨을 재검증했다. 실제 읽기 계측은 허용된 코드 8개만 확인했다. 문서 상대 링크 12/12와 `git diff --check` 통과. 서비스 소스 변경이 없어 앱 재빌드·원격 빌드·기기 설치는 실행하지 않았다.

동결된 도구 SHA-256: `25712c8d7e409e6f4f868963383dbac08eb3060fc40fdae2dbd74ce9bfe7134a`, 시험 파일: `b1ef18834f5e96ebdbe94b60739f0eb6336b6a7df7349f2bfb4a02a3c4ab03c9`. 이전 iOS 빌드의 증거 커밋은 `1954bfd8`이며 이번 문서·도구 커밋을 새 앱 빌드로 표시하지 않는다.

## 제출 기준과 증거 구분

- iOS 제출 최소 SDK는 2026-04-28부터 iOS 26 SDK 기준이다. #2의 새 SDK 컴파일은 이 조건의 일부 근거일 뿐 서명·기기 동작·심사 통과 근거가 아니다. [Apple 안내](https://developer.apple.com/news/?id=ueeok6yw)
