# 관리자 업무 화면 정리 · 검증 결과

2026-10-19 · 로컬 검증 완료, 푸시·배포 대기

## 적용 범위

관리자가 처음 들어왔을 때 처리할 요청과 오늘 수업을 바로 찾도록 정리했다. 라이트·라벤더 퍼플과 공식 로고를 유지하며 관리자 화면의 렌더링만 변경했다. API, 데이터 조회, 저장, 알림 발송 로직은 변경하지 않았다.

| 그룹 | 담당 | 의존 관계 | 완료 기준 |
|---|---|---|---|
| 첫 화면 정리 | 관리자 UI 담당 | 기존 데이터 계약 | 요청·오늘 수업 우선, 미조회 값 구분 |
| 메뉴 정리 | 탐색 UI 담당 | 기존 목적지 목록 | 주요 6개, 보조 2그룹, 기존 36개 주소 유지 |
| 통합 검증 | 독립 tester·reviewer / PM | 두 구현 완료 | 화면·행동·타입 검사, 차이 검토 |

## 달라진 화면

- 큰 소개 영역과 중복 빠른 관리 링크 8개를 제거했다. 해당 기능은 메뉴에서 계속 접근한다.
- 첫 화면에는 처리할 요청과 오늘 수업을 우선 배치했다. 기존 초기 응답에 포함된 오늘 수업을 추가 조회 전에도 보여준다.
- 통계·수익·최근 원생은 기본 접힘인 ‘운영 현황’으로, 시스템 상태·운영 도구는 ‘관리 도구’로 옮겼다.
- 주요 메뉴는 오늘 업무, 신청 관리, 원생 관리, 수업·출결, 수납·청구, 셔틀 관리다. 나머지는 ‘신청·수업 업무’와 ‘학원 운영 설정’으로 묶었다.
- 세부 주소로 직접 진입하면 해당 메뉴 그룹이 열리고 현재 메뉴 하나를 표시한다. 모바일 메뉴는 목적지를 선택하면 닫힌다.
- 아직 조회하지 않은 최근 원생·수익을 0건·0원으로 단정하지 않는다. 상세 조회 실패는 기존 오늘 수업을 유지하며 재조회 버튼을 제공한다.
- 영역을 펼치는 행동만으로 조회·운영 도구 실행·알림 발송을 시작하지 않는다.

변경 코드: `src/app/admin/AdminDashboardClient.tsx`, `src/app/admin/AdminShellClient.tsx`.

화면 검사는 1440·1024·768·390·320px의 일반/큰 글씨, 키보드 접기 조작, 모바일 이동, 세부 주소 5곳, 조회 503 후 재시도를 포함한다. 보호된 격리 테스트에서 실제 컴포넌트·Tailwind·공통 테마를 사용했으며 인증과 API는 모의 응답이다. 실제 운영 DB·로그인·발송·배포 검증을 뜻하지 않는다.

확대 회귀의 실패 1건은 `tests/pos-reconcile-service.test.mjs:260`의 저장소 전체 탐색 검사다. Git에 포함되지 않은 `.claude/worktrees/` 아래 기존 사본 6개까지 찾아 POS 매칭 코드가 여러 벌이라고 판정한다. 이번 작업은 POS 코드와 해당 검사를 변경하지 않았으며 기존 작업 폴더도 건드리지 않았다. 나머지 145건은 통과했다.

## 남은 범위

- 초기 서버 조회 자체가 실패했을 때 일부 기존 응답을 0 또는 빈 배열로 대체하는 계약은 그대로다. 이번 미조회 표시 개선과 구분해야 한다.
- 학부모·선생님·기사님 추가 UX 정리는 이번 변경에 포함하지 않았다. 다음 후보는 학부모 화면의 반복 카드·중복 진입점이다.
- 운영 DB 쓰기·외부 발송·푸시·배포는 수행하지 않았다. 배포는 결과 검토 후 별도 진행한다.
